# Security

| Area | Control |
|---|---|
| Source | Gitleaks scans the full Git history on every push (blocking) |
| Dependencies | Trivy: HIGH/CRITICAL vulnerabilities with a fix block the pipeline |
| Image | Non-root user (`node`), read-only root filesystem, Trivy image scan before push, immutable tags |
| Secrets | Database password generated by RDS, stored in Secrets Manager, injected by ECS; never in Git/image/state |
| Network | Tasks accept traffic only from the ALB; the database only from this environment's tasks; database in private subnets |
| Data in transit | App ↔ database TLS verified against the RDS CA bundle |
| CI → AWS | GitHub OIDC, no stored keys. Build role: ECR only. Deploy role per environment, usable only from that GitHub Environment |
| Production changes | `main` only, required approval (GitHub Environment `prod`), blue/green with automatic rollback |
| Runtime permissions | The task role has no AWS permissions by default; add only what the code needs |
